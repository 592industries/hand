# Evaluation set

The cases in `cases.json` are synthetic and safe to use. They separate transcription checks from comparison/scoring checks and describe the note image that should accompany each reference. No model-quality claim is made until those images are supplied to an authenticated deployed app and the observations are recorded.

Evaluate transcription with character/term accuracy, equation symbol fidelity, structural preservation, and uncertainty calibration. Evaluate comparison with concept classification, evidence grounding, applicable-dimension handling, and deterministic score reproduction.
